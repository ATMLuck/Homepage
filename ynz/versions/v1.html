项目介绍

樱奈子 Bot 是一个基于 Windows Server 环境部署的 QQ 智能聊天机器人项目。作为项目的初始版本，v1.0 奠定了整个系统的基础架构，实现了与 QQ 平台的对接和基础对话能力。

本版本采用 AstrBot 框架作为基础，配合 go-cqhttp 协议端，实现了在 Windows Server 环境下的稳定运行。

Windows Server 部署

基于 Windows Server 2019/2022 环境，利用 Windows 生态优势，简化部署流程，降低维护门槛。

QQ 协议对接

通过 go-cqhttp 协议端实现与 QQ 平台的对接，支持群聊和私聊消息收发。

基础 AI 对话

接入主流 LLM 模型，实现智能对话能力，支持上下文理解和多轮对话。

基础功能

智能对话

接入大语言模型，支持自然语言对话、知识问答、文本生成等功能。支持上下文记忆，可进行多轮连续对话。

群聊管理

支持群聊消息监听和回复，可配置群白名单/黑名单，设置群专属触发词，实现群内智能助手功能。

指令系统

内置基础指令系统，支持帮助查询、状态查看、配置管理等功能。可通过指令动态调整机器人行为。

权限管理

支持分级权限控制，区分管理员和普通用户，可设置指令使用权限，保障系统安全性。

常用指令

指令 权限 说明
/help 所有人 查看帮助信息
/status 所有人 查看机器人运行状态
/ping 所有人 测试机器人响应
/reload 管理员 重载配置文件

版本说明

v1.0 是樱奈子 Bot 的初始版本，标志着项目的正式启动。作为基础版本，它提供了最核心的功能：

  • 完整的 Windows Server 部署方案
  • QQ 平台的消息收发能力
  • 大语言模型对话集成
  • 基础的权限和指令系统

虽然功能相对简单，但 v1.0 为后续的 v2.0、v3.0 版本奠定了坚实的技术基础。在此版本中积累的经验，帮助项目逐步从 Windows 环境迁移到更高效的 Linux + Docker 架构。
