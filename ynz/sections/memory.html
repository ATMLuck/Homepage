02 / Memories

记忆与回忆

通过自然语言回忆聊天内容，也可以手动搜索、添加和整理属于当前会话的记忆。

自然提问

你可以直接问：「我们上次聊到的旅行计划是什么？」在群聊中也可以问：「昨天大家讨论了什么？」群聊历史查询只针对当前群，结果受记录范围和权限限制。

查找与记录

发送指令能做什么
/mcomp status查看记忆状态。
/mcomp search <关键词> [数量]搜索当前可见的记忆。
/mcomp explain <关键词> [数量]查看某条记忆为何被找到。
/mcomp recent [数量]
/mcomp timeline [数量]		查看近期记忆和时间线。
/mcomp add <内容>手动记下一件事。
/mcomp summarize立即整理当前会话。
/mcomp relations [数量] [实体ID]
/mcomp threads list		查看关系线索与延续中的话题。
/陪伴 画像
/陪伴 记忆
/陪伴 长期记忆		从陪伴视角查看已形成的资料和记忆。
例：/mcomp search 上次约好的电影 5；想让樱奈子记住约定，可以发送 /mcomp add 周六下午去看电影。

整理与维护 · 进阶

发送指令能做什么
/mcomp visibility <记忆ID> <可见性>
/mcomp promote <记忆ID>
/mcomp archive <记忆ID>		调整单条记忆的可见范围、优先级或归档状态。
/mcomp delete <记忆ID>删除指定记忆；操作前确认编号。
/mcomp diagnostics
/mcomp maintenance		查看诊断信息并运行维护。
/mcomp sleep status
/mcomp sleep run		查看或手动进行记忆整理。
/mcomp audit preview [数量]
/mcomp audit status <批次ID>		预览并检查记忆审计结果。
/mcomp data export导出记忆档案；涉及个人内容，请妥善保管。
/mcomp logs [数量]
/mcomp threads close <线程ID>		查看运行记录，或关闭一条延续中的话题。
清空范围、导入数据和应用审计会改变记忆资料，建议只由了解数据范围的管理员操作。私聊与群聊的可见范围不同。
