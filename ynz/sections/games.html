游戏与娱乐

查询《原神》《崩坏：星穹铁道》《绝区零》账号资料，也能签到、抽今日运势和点歌。

游戏查询通常直接发送下列文字，不加斜杠。先绑定自己的 UID；便签、签到、抽卡等部分数据还需要账号授权。请在私聊完成登录。

签到、运势与音乐

发送指令能做什么
/skdhelp
/skdlogin <Token>		查看森空岛签到帮助、登录账号；登录信息请在私聊发送。
/skd
/skdusers
/skdlogout		查看签到状态、账号列表，或退出登录。
/jrys 或 /今日运势获取今日运势图。
/jrysn
/jrysl source <图源>		尝试随机背景或选择运势图源。
/jrysl last
/jrysl none source <图源>		查看上次选用的图源，或取消指定图源。
/点歌 <歌名>搜索歌曲；若返回多个结果，再按提示发送对应序号。
