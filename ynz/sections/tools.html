07 / Handy tools

工具与管理

遇到不知道怎么用的功能，先看帮助菜单；下方还列出了运行状态与管理员常用入口。

每个人都能用

发送指令能做什么
/帮助 或 /helps查看当前机器人菜单；也可试 /菜单、/功能。
/状态 或 /status查看服务器运行状态图。
/当前余额查询
/所有余额查询		查看模型账户余额；是否向普通用户开放由当前设置决定。
/黑名单统计
/缓存统计		查看情感功能的统计信息。

管理员：陪伴与情绪

发送指令能做什么
/陪伴 删除日程 <时间/序号/活动名>
/陪伴 删除话头 <关键词/全部>		移除日程或对话线索。
/陪伴 查看提示词 <日程/细化/主动/回复注入>查看相应的陪伴设置内容。
/陪伴 答疑确认
/陪伴 答疑取消
/陪伴 答疑设置 <配置项> <值>		确认、取消或调整陪伴诊断提出的设置。
/陪伴 撤回消息
/陪伴 清空记忆
/陪伴 重置当前人格
/陪伴 重置插件		撤回消息或重置资料；执行前请确认影响范围。
/设置情感 <用户> <维度> <数值>
/重置好感 <用户>
/查看好感 <用户>		查看或调整指定用户的情感状态。
/reset_emotion [uid]
/reset_current [uid]
/reset_all_emotions		重置另一组情绪记录；最后一条会影响全部用户。
/set_emotion ...手动调整情绪数据；具体参数以指令返回的提示为准。

管理员：记忆与内容

发送指令能做什么
/mcomp clear_scope group <群号> [清空]
/mcomp clear_scope private <QQ> [清空]		预览或清空指定群聊、私聊范围的记忆；带「清空」才会执行。
/mcomp clear_scope group_member <群号> <QQ> [清空]预览或清空某位群成员在指定群内的记忆。
/mcomp audit apply <批次ID> 确认
/mcomp audit rollback <批次ID> 确认		应用或回滚记忆审计结果。
/mcomp preset status
/mcomp preset apply light|standard|companion		查看或切换记忆工作模式。
/mcomp data preview <路径>
/mcomp data import <路径>		预览或导入记忆档案。
/画图工作流查看绘图工作流入口；需已配置图片服务。
/meme on
/meme off
/meme status		控制表情包功能并查看状态。其他管理参数可从 /meme menu 查看。
/meme auto_on
/meme auto_off
/meme group
/meme 偷		控制自动发送、群范围与短时收集。
/meme list
/meme clean
/meme capacity
/meme delete		查看和整理表情包库。
/meme blacklist
/meme scope
/meme rebuild_index		管理收集范围、黑名单与检索索引。
/meme natural_analysis
/meme emotion_stats
/meme clear_emotion_cache
/meme tag_stats		分析表情使用情况并维护情绪标签缓存。

管理员：服务与群功能

发送指令能做什么
/连接core手动重连游戏数据服务。
/清除日报缓存清理晨报缓存。
/lc订阅
/lc退订
/lc全部订阅		管理群内每日题目推送。
/开启解析
/关闭解析
/登录B站		管理媒体链接解析及登录状态。
/备份数据备份情感数据。

管理员还可以在管理面板中调整页面配色、统计显示，以及部分陪伴、绘图和群聊功能的开关。

删除、重置、导入和清空类操作会影响已有资料。管理员应先确认目标用户、群聊和数据范围。
